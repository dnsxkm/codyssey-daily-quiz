🥉 브론즈 # 파이썬 문제 풀이

합격자 성적 통계

시간 제한 1초 · 메모리 128MB · 반복문 · 조건문 · 예외 상황 처리

문제

학생들의 시험 점수가 주어집니다. 60점 이상이면 합격입니다.

합격자에 대해 인원 수, 평균 점수, 최고 점수를 구하세요.

단, 합격자가 한 명도 없으면 인원 수 0을 출력한 뒤 다음 줄에 NONE을 출력합니다.

입력

첫째 줄에 학생 수 N이 주어집니다. (1 ≤ N ≤ 100)

둘째 줄에 N개의 점수가 공백으로 구분되어 주어집니다. (0 ≤ 점수 ≤ 100)

출력

첫째 줄에 합격자 수를 출력합니다.

합격자가 있으면 둘째 줄에 평균 점수(소수점 버림), 셋째 줄에 최고 점수를 출력합니다.

합격자가 없으면 둘째 줄에 NONE을 출력합니다.

예제

예제 입력 1
5
85 40 92 60 30
예제 출력 1
3
79
92

합격자는 85, 92, 60 → 3명 · 합계 237 ÷ 3 = 79 · 최고 92

예제 입력 2
3
10 20 30
예제 출력 2
0
NONE

60점 이상이 없으므로 0과 NONE만 출력

힌트

    

      힌트 1 — 한 줄에 여러 숫자 받기
      

        점수가 한 줄에 전부 들어옵니다. 공백으로 나눈 뒤 모두 숫자로 바꿔 리스트에 담으면 편해요.
        
scores = list(map(int, input().split()))

        
이러면 [85, 40, 92, 60, 30] 처럼 되어 for s in scores:로 하나씩 꺼내 쓸 수 있어요.

      

    


    

      힌트 2 — 세 가지를 한 번에 구하기
      

        반복문을 세 번 돌 필요 없어요. 한 번 돌면서 변수 세 개를 같이 갱신하면 됩니다.
        
total = 0    # 합격자 점수 합
count = 0    # 합격자 수
best = 0     # 최고 점수

        
합격(60점 이상)일 때만 total에 더하고, count를 1 늘리고, 지금까지의 best보다 크면 best를 바꿔줍니다.

        
평균은 소수점을 버려야 하니 / 가 아니라 // 를 씁니다.

      

    


    

      힌트 3 — 합격자가 없을 때
      

        합격자가 0명인데 total // count 를 계산하면 0으로 나누기가 되어 프로그램이 죽습니다(ZeroDivisionError).
        
if count > 0:
    print(total // count)
    print(best)
else:
    print("NONE")

        
그래서 나누기 전에 합격자가 있는지 먼저 확인해야 해요. 이 문제에서 가장 놓치기 쉬운 부분입니다.

      

    


    
정답

    

      정답 코드 보기
      

        
n = int(input())
scores = list(map(int, input().split()))

total = 0
count = 0
best = 0

for s in scores:
    if s >= 60:
        total += s
        count += 1
        if s > best:
            best = s

print(count)
if count > 0:
    print(total // count)
    print(best)
else:
    print("NONE")

        
흐름을 정리하면

        
• 변수 세 개를 반복문 밖에서 0으로 시작합니다.

        
• if s >= 60 — 합격자만 골라서 처리. 60점도 합격이니 > 가 아니라 >= 입니다.

        
• if s > best — 더 큰 점수를 만날 때만 갱신. 이렇게 하면 반복이 끝났을 때 best에 최댓값이 남아요.

        
• total // count — //는 소수점을 버리는 나눗셈. /를 쓰면 79.0처럼 나와 틀립니다.

        
• 마지막 if count > 0 가 0으로 나누기를 막아주는 안전장치예요.

      

    


    

      다른 풀이 — 합격자만 리스트로 모으기
      

        조건에 맞는 것만 먼저 걸러내면 나머지는 내장 함수로 해결됩니다.
        
passed = [s for s in scores if s >= 60]

print(len(passed))
if passed:
    print(sum(passed) // len(passed))
    print(max(passed))
else:
    print("NONE")

        
sum, len, max를 쓰니 훨씬 짧아요. if passed: 는 리스트가 비어있지 않으면 참이라는 성질을 이용한 겁니다.

      

    


    

      자주 하는 실수
      

        
🔸 합격자가 없을 때를 안 막음 → ZeroDivisionError로 프로그램이 죽습니다. 예제 2로 꼭 확인하세요.

        
🔸 > 와 >= 혼동 → 60점은 합격입니다. s > 60 이라고 쓰면 60점이 빠져요.

        
🔸 / 를 씀 → 79.0 처럼 소수점이 붙어 틀립니다. // 를 쓰세요.

        
🔸 best의 시작값을 100으로 둠 → 최댓값을 찾을 땐 작은 값에서 시작해야 갱신됩니다. 점수가 0 이상이므로 0으로 시작하면 안전해요.

        
🔸 합격자 수를 조건 안에서만 출력 → 합격자가 없어도 0은 항상 출력해야 합니다.
