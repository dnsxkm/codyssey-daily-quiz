# 파이썬 기초 · 데일리 퀴즈

🌱 기본 개념 다지기

파이썬을 막 시작했다면 여기서부터. 자료형 · 연산자 · 조건문 · 반복문 · 자료구조의 가장 기본이 되는 개념들이에요. 어려운 응용은 없고, 알고 있는지 확인하는 문제들입니다. 12문제.

▚ PART 1 · 자료형과 변수

값의 종류를 구분하는 게 모든 것의 시작.

문제 1 자료형
3.14의 자료형은?
정답: float. 소수점이 있는 숫자는 float(실수)예요. 3처럼 소수점이 없으면 int(정수), "3"처럼 따옴표로 감싸면 str(문자열)입니다. type(3.14)로 직접 확인할 수 있어요.
문제 2 타입 오류
"3" + 3 을 실행하면?
정답: TypeError. "3"은 문자열, 3은 숫자라 서로 더할 수 없어요. 파이썬은 "문자열에는 문자열만 이어붙일 수 있다"며 오류를 냅니다. 계산하려면 int("3") + 3으로 형변환을, 이어붙이려면 "3" + str(3)으로 맞춰줘야 해요.
문제 3 input
input()으로 받은 값의 자료형은 항상 무엇일까요?
정답: 항상 str. 사용자가 5를 입력해도 파이썬은 문자열 "5"로 받아요. 그래서 input() + 1은 TypeError가 나고, 계산하려면 int(input())처럼 숫자로 바꿔줘야 합니다. 초보자가 가장 많이 만나는 오류 중 하나예요.
▚ PART 2 · 연산자

계산과 비교의 규칙.

문제 4 나눗셈
7 // 2 와 7 % 2 의 결과는?
정답: 3 그리고 1. //는 몫(소수점 버림), %는 나머지예요. 7을 2로 나누면 몫 3, 나머지 1이죠. 참고로 그냥 /는 3.5처럼 실수를 돌려줍니다. 인덱스처럼 정수가 필요한 자리엔 //를 써야 해요.
문제 5 = 과 ==
= 와 == 의 차이는?
정답: 2번. x = 5는 "x에 5를 넣어라", x == 5는 "x가 5와 같은가?"예요. 조건문에 실수로 if x = 5:라고 쓰면 문법 오류(SyntaxError)가 납니다. 대입은 하나, 비교는 둘로 외우면 편해요.
문제 6 논리 연산
5 > 3 and 2 > 4 의 결과는?
정답: False. and는 양쪽이 모두 참이어야 True예요. 5 > 3은 True지만 2 > 4는 False라서 전체는 False. 만약 or였다면 한쪽만 참이어도 True가 되어 결과가 True였을 거예요.
▚ PART 3 · 조건문과 반복문

흐름을 나누고, 되풀이하기.

문제 7 출력 예측
출력은?
score = 85
if score >= 90:
print("A")
elif score >= 80:
print("B")
elif score >= 70:
print("C")
정답: B. 조건은 위에서부터 차례로 검사돼요. 85는 90 이상이 아니라 첫 조건은 통과, 80 이상이니 elif score >= 80에서 걸려 "B"를 출력합니다. 그리고 하나가 맞으면 나머지는 건너뛰어요 — 그래서 score >= 70도 참이지만 "C"는 나오지 않습니다.
문제 8 range
for i in range(3): 에서 i에 들어가는 값은?
정답: 0, 1, 2. range(3)은 0부터 시작해서 3 직전까지, 즉 세 개의 값을 만들어요. 끝 숫자는 포함되지 않는다는 게 핵심입니다. 1부터 3까지 원하면 range(1, 4)라고 써야 해요.
문제 9 들여쓰기
파이썬에서 들여쓰기가 하는 일은?
정답: 2번. 다른 언어가 중괄호 { }로 묶는 범위를, 파이썬은 들여쓰기로 표현해요. 그래서 들여쓰기를 빠뜨리거나 어긋나면 IndentationError가 납니다. 보통 공백 4칸을 쓰고, 한 파일 안에서 방식을 섞지 않는 게 중요해요.
▚ PART 4 · 자료구조

여러 값을 담는 그릇들.

문제 10 인덱스
a = [10, 20, 30, 40, 50] 일 때 a[0] 과 a[-1] 은?
정답: 10 과 50. 파이썬 인덱스는 0부터 시작하니 a[0]은 첫 번째인 10이에요. 그리고 음수 인덱스는 뒤에서부터 세는 것이라 a[-1]은 맨 마지막인 50입니다. a[5]처럼 범위를 벗어나면 IndexError가 나요.
문제 11 리스트 vs 튜플
리스트 [1,2,3] 와 튜플 (1,2,3) 의 가장 큰 차이는?
정답: 2번. 리스트는 a[0] = 9처럼 수정·추가·삭제가 되지만, 튜플은 한 번 만들면 바꿀 수 없어요(TypeError). 그래서 좌표 (x, y)처럼 바뀌면 안 되는 값을 묶을 때 튜플을 씁니다. 둘 다 순서는 있어요.
문제 12 딕셔너리
d = {"a": 1} 에서 d["z"] 로 없는 키에 접근하면?
정답: KeyError. 딕셔너리는 {키: 값} 짝으로 저장하는데, 없는 키를 대괄호로 찾으면 오류가 나요. 안전하게 꺼내려면 d.get("z", 0)처럼 기본값을 주면 됩니다 — 키가 없을 때 오류 대신 0을 돌려줘요.
