# 파이썬 개념 · 데일리 퀴즈 (중급)

🧭 알아두면 쓸모 있는 개념들

기초는 넘었지만 아직 헷갈리는 것들이에요. 복사와 참조, 반환값, 자주 쓰는 내장 함수와 메서드 중심입니다. 실제 코드를 짜다 보면 반드시 만나는 것들이라, 여기서 정리해두면 바로 쓸 수 있어요. 12문제.

▚ PART 1 · 복사와 참조

이름표와 값의 관계.

문제 1 참조
출력은?
a = [1, 2, 3]
b = a
b.append(4)
print(a)
정답: [1, 2, 3, 4]. b = a는 리스트를 복사하는 게 아니라, 같은 리스트에 이름표를 하나 더 붙이는 거예요. a와 b가 같은 것을 가리키니 b로 바꿔도 a에 보입니다. 진짜 복사본이 필요하면 b = a[:] 또는 b = a.copy()를 쓰세요.
문제 2 복사
이번엔 [:]를 썼어요. 출력은?
c = [1, 2, 3]
d = c[:]
d.append(4)
print(c)
정답: [1, 2, 3]. c[:]는 새 리스트를 만들어 값을 옮겨 담아요. 그래서 d를 바꿔도 c는 그대로입니다. 원본을 지키면서 정렬하거나 섞고 싶을 때 이 방법을 씁니다. (단, 리스트 안에 리스트가 들어있는 경우엔 안쪽까지는 복사되지 않아요.)
문제 3 문자열
출력은?
s = "hello"
s.upper()
print(s)
정답: hello. 문자열 메서드는 원본을 바꾸지 않고 새 문자열을 돌려줘요. 돌려받은 값을 어디에도 담지 않았으니 그냥 사라집니다. 대문자로 바꾸려면 s = s.upper()처럼 다시 대입해야 해요. strip(), replace()도 전부 마찬가지입니다.
▚ PART 2 · 반환값

무엇이 돌아오는지 알아야 제대로 쓴다.

문제 4 sort
출력은?
nums = [3, 1, 2]
result = nums.sort()
print(result)
정답: None. .sort()는 리스트를 제자리에서 정렬하고 아무것도 돌려주지 않아요(None). nums 자체는 [1,2,3]으로 정렬되지만, result엔 None이 담깁니다. 정렬된 새 리스트를 받고 싶다면 result = sorted(nums)를 쓰세요.
문제 5 return
출력은?
def double(n):
print(n * 2)
 
x = double(5)
print(x)
정답: 10 다음 None. print()는 화면에 보여줄 뿐이고, 값을 돌려주는 건 return이에요. double 안에 return이 없으니 파이썬이 자동으로 None을 돌려줍니다. 계산 결과를 나중에 쓰려면 return n * 2로 바꿔야 해요.
문제 6 기본 인자
두 번 호출했어요. 두 번째 출력은?
def add(x, box=[]):
box.append(x)
return box
 
print(add(1)) # [1]
print(add(2)) # ?
정답: [1, 2]. 기본값 []는 함수를 정의할 때 딱 한 번 만들어져요. 호출할 때마다 새로 생기는 게 아니라서 같은 리스트에 계속 쌓입니다. 그래서 리스트·딕셔너리를 기본값으로 쓰지 말라고 하죠. 대신 def add(x, box=None):로 두고 안에서 if box is None: box = []로 만들면 됩니다.
▚ PART 3 · 자주 쓰는 도구들

알면 코드가 짧아지는 것들.

문제 7 슬라이싱
x = [10, 20, 30, 40, 50] 일 때 x[1:3] 은?
정답: [20, 30]. 슬라이싱은 시작은 포함, 끝은 제외예요. 인덱스 1(=20)부터 3 직전인 2(=30)까지입니다. range()와 같은 규칙이죠. 참고로 x[:2]는 앞 두 개, x[-2:]는 뒤 두 개를 뜻해요.
문제 8 dict.get
d = {"a": 1} 일 때 d.get("z", 0) 의 결과는?
정답: 0. d["z"]로 없는 키를 찾으면 KeyError가 나지만, .get()은 기본값을 돌려줘요. 두 번째 인자를 생략하면 None이 나옵니다. 개수를 셀 때 d[k] = d.get(k, 0) + 1 같은 관용구로 자주 쓰여요.
문제 9 enumerate
for i, v in enumerate(["a", "b"]): 에서 첫 번째 i 값은?
정답: 0. enumerate는 번호와 값을 함께 꺼내주는 함수로, 번호는 기본적으로 0부터 시작해요. 1위, 2위처럼 1부터 세고 싶다면 enumerate(목록, start=1)이라고 쓰면 됩니다. 인덱스가 필요할 때 range(len(...))보다 훨씬 깔끔해요.
문제 10 컴프리헨션
[n for n in range(6) if n % 2 == 0] 의 결과는?
정답: [0, 2, 4]. 리스트 컴프리헨션은 "뽑을 값 for 변수 in 대상 if 조건" 구조예요. range(6)은 0~5이고 그중 2로 나눈 나머지가 0인 것만 남기니 0, 2, 4입니다. 0도 짝수라는 걸 놓치기 쉬워요. for문 3~4줄을 한 줄로 줄여주는 문법입니다.
▚ PART 4 · 판단과 비교

참·거짓과 포함 여부.

문제 11 진리값
다음 중 if에서 참으로 취급되는 것은?
정답: "0". 파이썬은 비어 있거나 0이면 거짓으로 봐요. 그런데 "0"은 글자 하나가 들어있는 문자열이라 참입니다. 안이 뭐든 비어있지만 않으면 참이에요. input()으로 받은 값은 항상 문자열이라, 사용자가 0을 입력해도 참이 되니 주의해야 합니다.
문제 12 in 연산자
d = {"a": 1, "b": 2} 일 때 1 in d 의 결과는?
정답: False. 딕셔너리에 in을 쓰면 키만 확인해요. 키는 "a", "b"이고 1은 값이라 False입니다. 값에서 찾으려면 1 in d.values()라고 써야 해요. 참고로 리스트나 문자열에서는 in이 원소·부분문자열 포함 여부를 확인합니다.
