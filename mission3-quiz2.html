# 과제3 · 데일리 퀴즈 ② (난이도 중)

⚙️ 판정 로직 · 라벨 정규화 · O(N²)

난이도 하에서 감을 잡았다면, 이번엔 실제 구현에서 걸리는 지점이에요. 판정 함수의 순서, 정규화를 빠뜨렸을 때 생기는 FAIL, 이중 for문의 복잡도까지. 7문제(총 10칸)입니다.

문제 2 순서
만약 decide()에서 동점(EPSILON) 검사를 맨 마지막으로 옮기면?
정답: 2번. cross > x 비교는 아주 미세한 차이도 크다/작다로 갈라버려요. 0.9와 0.8999999999도 >로 보면 엄연히 크니까 CROSS가 나옵니다. 그래서 동점 검사를 먼저 해서 걸러낸 다음에 크기 비교를 해야 UNDECIDED가 제대로 나와요. 조건문은 위에서부터 검사되니 순서가 곧 로직입니다.
문제 3 출력 예측
정규화를 빠뜨린 비교예요. 출력은?
result = "CROSS" # 판정 결과
expected = " Cross " # JSON 속 정답
print(result == expected)
정답: False. 사람 눈엔 같은 답이지만 문자열로는 완전히 다른 값이에요 — 앞뒤 공백도 있고 대소문자도 다르니까요. 맞는 답인데 FAIL로 집계되는 이유가 이겁니다. expected.strip().upper()로 정규화하면 "CROSS"가 되어 True가 돼요.

문제 5 복잡도
MAC 연산에서 N이 5 → 25로 5배 커지면, 연산 횟수는 몇 배?
정답: 25배. 이중 for문이라 칸 수는 N×N. N=5면 25칸, N=25면 625칸이니 625 / 25 = 25배예요. O(N²)에서 N이 k배가 되면 연산은 k²배가 된다는 뜻 — 5배 커지면 25배입니다.
문제 6 입력 검증
사용자가 "1 2 삼"을 입력했어요. float("삼")에서 발생하는 예외는?
정답: ValueError. float()는 타입은 맞지만(문자열) 값이 숫자로 해석 불가할 때 ValueError를 던져요. int("abc")와 같은 상황입니다. 그래서 read_grid()에서 except ValueError:로 잡아 "숫자를 입력하세요"라고 안내하고 다시 받는 거예요.
문제 7 단답
모드2에서 data.json을 읽을 때, 파일이 없을 경우 발생하는 예외 이름은?
정답: FileNotFoundError. open("data.json") 했는데 그 경로에 파일이 없으면 FileNotFoundError가 나요. 파일이 있어도 내용이 깨진 JSON이면 json.JSONDecodeError가 따로 발생하니, 실무에선 둘 다 잡아 안내 메시지를 띄웁니다.
빈칸·단답 정답은 대소문자·공백에 관계없이 채점돼요.
