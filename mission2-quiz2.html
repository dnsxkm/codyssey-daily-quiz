# 과제2 · 데일리 퀴즈 ② (심화)

🧠 응용·변형 심화 6문제 — 개념이 진짜 붙었나?

앞서 배운 변수 범위·복사·반복·예외 처리 개념을, 이번엔 새로운 코드에 적용하고 살짝 비틀어 봤어요. 객관식·출력 예측·빈칸이 섞여 있고, 얕은 복사·else/finally·예외 던지기 같은 한 단계 깊은 내용이 들어갑니다. 6문제를 다 풀고 채점하기를 눌러보세요.

문제 1 변형
아래 코드를 실행하면 print(picked)의 출력은?
import random
 
questions = ["Q1", "Q2", "Q3"]
picked = random.shuffle(questions)
print(picked)
정답: None. shuffle()는 리스트를 그 자리에서 직접 섞고, 반환값은 None이에요. 그래서 picked엔 None이 담깁니다. 이래서 리스트를 섞을 땐 order = cards[:]로 복사본을 만든 뒤 random.shuffle(order)처럼 넘긴 리스트 자체를 섞어요 — 반환값을 받아 쓰는 게 아니라요.
문제 2 응용
다른 클래스예요. 이 코드를 실행하면?
class Counter:
def __init__(self):
count = 0
def bump(self):
self.count += 1
 
c = Counter()
c.bump()
정답: AttributeError. __init__ 안의 count = 0은 self.count가 아니라 잠깐 쓰고 사라지는 지역 변수예요. 그래서 객체엔 count가 저장되지 않고, bump()의 self.count += 1에서 "그런 속성 없음" → AttributeError. self vs 지역 변수 규칙은 클래스만 바뀌어도 똑같이 적용됩니다. 고치려면 self.count = 0.
문제 3 심화
[:]로 복사했는데도… 출력은?
grid = [[1, 2], [3, 4]]
shallow = grid[:]
shallow[0].append(99)
print(grid)
정답: [[1, 2, 99], [3, 4]]. grid[:]는 바깥 리스트만 새로 만드는 얕은 복사예요. 안에 든 [1, 2]와 [3, 4]는 여전히 원본과 같은 객체를 가리켜서, shallow[0].append(99)가 grid[0]까지 바꿔버립니다. 그래서 [[1, 2, 99], [3, 4]]. [:]가 "완전 복사"가 아니라 한 겹만 복사라는 것 — 중첩 구조까지 완전히 떼어내려면 copy.deepcopy()를 써요.
문제 4 심화
무엇이, 어떤 순서로 출력될까요?
try:
x = int("5")
except ValueError:
print("A")
else:
print("B")
finally:
print("C")
정답: "B" 다음 "C". int("5")는 성공해서 except ValueError는 건너뛰어요. else는 try에서 예외가 안 났을 때만 실행되니 "B". finally는 예외 여부와 상관없이 항상 실행 → "C". 그래서 B, C 순서. (만약 try에서 예외가 났다면 except가 "A"를 찍고, else는 건너뛰고, finally "C"가 나왔겠죠.)
문제 5 심화
이번엔 무한히 묻지 않고, 정해진 횟수만 시도하고 실패하면 예외를 던지는 함수예요. 빈칸 3개를 채우세요.
def read_int(prompt, max_tries=3):
for _ in range():
try:
return int(input())
except ValueError:
print("숫자가 아니에요. 다시 입력하세요.")
ValueError("여러 번 틀렸습니다.")
정답: max_tries, prompt, raise. 무한 반복 대신 정해진 횟수(max_tries)만큼만 시도해요. 성공하면 return으로 바로 빠져나가고, for가 끝날 때까지 한 번도 성공 못 하면 루프 아래 줄로 내려와 raise로 예외를 직접 던집니다. raise는 "여기서 문제가 생겼다"고 알리며 흐름을 멈추는 명령이에요. 무한히 다시 묻던 while True 버전과 달리, 몇 번 실패하면 포기하고 호출한 쪽에 알려주는 구조죠.
문제 6 응용
이 코드의 출력은?
scores = {"kim": 10}
print(scores.get("lee", 0))
정답: 0. scores["lee"]로 접근하면 없는 키라 KeyError가 나지만, scores.get("lee", 0)은 키가 없을 때 기본값 0을 돌려줘요. 저장 파일을 불러올 때 없는 항목 때문에 프로그램이 터지는 걸 예방하는 방법 — except KeyError로 잡아야 할 상황을 아예 안 생기게 막는 쪽이죠.
빈칸·출력 정답은 대소문자·공백에 관계없이 채점돼요.
