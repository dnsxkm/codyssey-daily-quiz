# 과제2 · 데일리 퀴즈 ③ (심화)

🧠 응용·변형 6문제 — 개념이 진짜 붙었나?

퀴즈①(변수 범위)·퀴즈②(반복+예외)에서 배운 걸 이번엔 내 코드가 아닌 새로운 상황에 적용하고, 살짝 비틀어 봤어요. 객관식·출력 예측·빈칸이 섞여 있고 전보다 조금 어렵습니다. 6문제를 다 풀고 아래 채점하기를 눌러보세요.

문제 1 퀴즈① 변형
아래 코드를 실행하면 print(picked)의 출력은?
import random
 
questions = ["Q1", "Q2", "Q3"]
picked = random.shuffle(questions)
print(picked)
정답: None. shuffle()는 리스트를 그 자리에서 직접 섞고, 반환값은 None이에요. 그래서 picked엔 None이 담깁니다. 퀴즈①에서 order = self.quizzes[:]로 복사본을 만든 뒤 random.shuffle(order)로 order를 직접 섞은 이유가 바로 이거예요 — 반환값을 받아 쓰는 게 아니라, 넘긴 리스트 자체가 섞이는 거죠.
문제 2 응용
다른 클래스예요. 이 코드를 실행하면?
class Counter:
def __init__(self):
count = 0
def bump(self):
self.count += 1
 
c = Counter()
c.bump()
정답: AttributeError. __init__ 안의 count = 0은 self.count가 아니라 잠깐 쓰고 사라지는 지역 변수예요. 그래서 객체엔 count가 저장되지 않고, bump()의 self.count += 1에서 "그런 속성 없음" → AttributeError. 퀴즈①의 self vs 변수 규칙이 클래스만 바뀌어도 똑같이 적용됩니다. 고치려면 self.count = 0.
문제 3 응용
출력값을 예측해서 적어보세요.
a = [1, 2, 3]
b = a
b.append(4)
print(len(a))
출력 →
정답: 4. b = a는 리스트를 복사하는 게 아니라, 같은 리스트에 이름표를 하나 더 붙이는 거예요. 그래서 b.append(4)면 a도 같이 커져서 len(a)는 4. 원본을 지키려면 b = a[:] 또는 b = a.copy(). 퀴즈①의 [:]가 왜 필요했는지가 정확히 이 이유예요.
문제 4 퀴즈② 응용
이 코드의 출력은?
try:
n = int("10")
result = 100 / (n - 10)
except ValueError:
print("A")
except ZeroDivisionError:
print("B")
정답: B. int("10")은 문제없이 10이 되고, 다음 줄 100 / (10 - 10) = 100 / 0에서 ZeroDivisionError가 나요. try 안에서 예외가 터지면 그 아래 줄은 건너뛰고, 종류가 맞는 except로 점프 → 두 번째 except가 잡아 "B". 첫 번째 except ValueError는 해당이 안 돼서 실행되지 않습니다.

문제 6 응용
이 코드의 출력은?
scores = {"kim": 10}
print(scores.get("lee", 0))
정답: 0. scores["lee"]로 접근하면 없는 키라 KeyError가 나지만, scores.get("lee", 0)은 키가 없을 때 기본값 0을 돌려줘요. 저장 파일을 불러올 때 없는 항목 때문에 프로그램이 터지는 걸 예방하는 방법 — 퀴즈 코드에서 except KeyError로 잡던 상황을, 아예 안 생기게 막는 쪽이죠.
빈칸·출력 정답은 대소문자·공백에 관계없이 채점돼요.
