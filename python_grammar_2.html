▚ 주제 1 · while문

횟수를 모를 때, 조건이 참인 동안 반복.

문제 1 출력 예측
반복이 끝난 뒤 출력은?
i = 0
while i < 3:
i += 1
print(i)
정답: 3. i가 0,1,2일 때 조건이 참이라 세 번 돌면서 i는 3이 돼요. 그 다음 3 < 3이 거짓이 되어 빠져나갑니다. 즉 반복이 끝나는 순간의 i는 조건을 처음 어긴 값이에요. 만약 i += 1을 빠뜨리면 조건이 영원히 참이라 무한 루프가 됩니다.
문제 2 for와 비교
while문이 for문보다 적합한 상황은?
정답: 2번. 횟수를 알면 for, 조건으로 끝내면 while이 기본 원칙이에요. 예를 들어 "사용자가 올바른 값을 넣을 때까지 계속 묻기"는 몇 번 만에 성공할지 모르니 while이 맞습니다. 반대로 리스트 순회나 정해진 횟수는 for가 더 간결하고 안전해요.
문제 3 break / continue
출력은?
result = []
i = 0
while i < 5:
i += 1
if i % 2 == 0:
continue
result.append(i)
print(result)
정답: [1, 3, 5]. continue는 이번 회차의 남은 부분만 건너뛰고 다시 조건 검사로 돌아가요. 짝수일 때 append를 건너뛰니 홀수만 담깁니다. 반면 break는 반복 자체를 완전히 끝내는 것이라 결과가 [1]이 됐을 거예요. continue는 건너뛰기, break는 탈출로 구분하세요.
문제 4 무한 루프
while True: 로 시작하는 반복문에서 빠져나오려면?
정답: 2번. True는 영원히 참이라 조건이 스스로 거짓이 될 수 없어요. 그래서 반드시 안에서 break(반복 탈출)나 return(함수 종료)으로 끊어야 합니다. "올바른 입력을 받을 때까지 계속 묻기" 같은 상황에서 성공하면 return 하는 식으로 자주 쓰여요.
▚ 주제 2 · 클래스

데이터와 기능을 하나로 묶는 틀.

문제 5 개념
클래스를 쓰는 가장 큰 이유는?
정답: 2번. 학생 100명을 관리한다면 이름·점수 변수를 100쌍 만드는 대신, Student 클래스 하나로 객체 100개를 찍어내면 돼요. 데이터(이름, 점수)와 기능(성적 계산)이 한 덩어리로 묶여 있어서 관리도 쉽습니다. 속도나 메모리 때문이 아니라 구조화가 목적이에요.
문제 6 출력 예측
객체를 두 개 만들었어요. 출력은?
class Student:
count = 0 # 클래스 속성
def __init__(self, name):
self.name = name
Student.count += 1
 
a = Student("민수")
b = Student("영희")
print(Student.count)
정답: 2. Student.count는 클래스에 하나만 있는 값이라 객체를 만들 때마다 공유된 카운터가 올라가요. 객체가 2개 만들어졌으니 2입니다. 이렇게 "지금까지 몇 개 만들어졌나" 같은 전체 통계를 클래스 속성으로 관리할 수 있어요. 반면 self.name은 객체마다 따로입니다.
문제 7 용어
클래스 안에 정의된 함수를 부르는 이름은?
정답: 메서드. 용어를 정리하면 — 클래스 안의 함수는 메서드, 클래스가 가진 값은 속성(attribute), 클래스로 만들어낸 실물은 인스턴스(객체)예요. a.name은 속성 접근이고 a.greet()는 메서드 호출입니다. 괄호가 붙으면 메서드라고 보면 쉬워요.
▚ 주제 3 · self

메서드 안에서 "나 자신"을 부르는 법.

문제 8 동작 원리
a.greet() 라고 호출하면 파이썬은 내부적으로 무엇과 같게 처리할까요?
정답: 2번. 점(.) 앞에 있는 객체가 자동으로 첫 인자가 돼요. 그래서 def greet(self):라고 매개변수를 하나 적어두면 거기에 a가 들어갑니다. 우리가 괄호 안에 아무것도 안 써도 되는 이유가 이거예요. 이 구조를 알면 self를 왜 적어야 하는지 자연스럽게 이해됩니다.
문제 9 빈칸
메서드가 같은 객체의 다른 메서드를 부르는 코드예요. 빈칸을 채우세요.
class Calc:
def __init__(self, n):
self.n = n
 
def double(self):
return self.n * 2
 
def quad(self):
# double을 두 번 적용
return * 2
정답: self.double() 같은 클래스 안에 있어도 그냥 double()이라고 쓰면 NameError가 나요. 메서드는 객체에 속해 있으니 반드시 self.를 붙여 "내 안의 double"이라고 지목해야 합니다. 속성이든 메서드든 객체의 것을 쓸 땐 항상 self.가 규칙이에요.
▚ 주제 4 · 딕셔너리

키로 값을 찾는 자료구조.

문제 10 순회
for k in d: 로 딕셔너리를 돌면 k에 들어오는 것은?
정답: 키. 딕셔너리를 그냥 for에 넣으면 키만 나와요. 값이 필요하면 d[k]로 꺼내거나, 처음부터 for k, v in d.items():로 둘 다 받으면 됩니다. 값만 필요하면 for v in d.values():를 쓰세요. in 연산자도 같은 규칙이라 "a" in d는 키를 찾습니다.
문제 11 items
d = {"a": 1} 일 때 list(d.items()) 의 결과는?
정답: [('a', 1)]. .items()는 (키, 값) 튜플들을 내놓아요. 그래서 for k, v in d.items():처럼 두 변수로 받아 쓸 수 있는 겁니다 — 튜플이 자동으로 풀리거든요(언패킹). 정렬할 때도 sorted(d.items(), key=...) 형태로 자주 씁니다.
문제 12 키 조건
딕셔너리의 키로 쓸 수 없는 것은?
정답: 리스트. 키는 변하지 않는 값이어야 해요. 리스트는 내용이 바뀔 수 있어서 키로 쓰면 TypeError: unhashable type이 납니다. 반면 튜플은 바꿀 수 없으니 키로 쓸 수 있어요 — 좌표 {(1,2): "보물"}처럼요. 이게 튜플의 실용적인 쓰임 중 하나입니다.
▚ 주제 5 · 튜플

한 번 만들면 바꿀 수 없는 묶음.

문제 13 함정
type((1)) 과 type((1,)) 의 결과는?
정답: int, tuple. 튜플을 만드는 건 괄호가 아니라 쉼표예요. (1)은 그냥 "괄호로 감싼 숫자 1"이라 int입니다. 원소가 하나인 튜플을 만들려면 뒤에 쉼표를 붙여 (1,)이라고 써야 해요. 실수하기 쉬운 문법이라 꼭 기억해두세요.
문제 14 언패킹
두 변수의 값을 맞바꾸는 코드예요. 출력은?
x, y = 1, 2
x, y = y, x
print(x, y)
정답: 2 1. 오른쪽 y, x가 먼저 튜플 (2, 1)로 묶인 뒤 왼쪽 변수들에 하나씩 풀려 들어가요(언패킹). 그래서 임시 변수 없이 한 줄로 값을 교환할 수 있습니다. 다른 언어에선 temp 변수를 만들어야 하는 작업이라, 파이썬의 대표적인 편의 문법이에요.
문제 15 불변성
t = (1, 2, 3) 일 때 t[0] = 9 를 실행하면?
정답: TypeError. 튜플은 불변(immutable)이라 원소를 바꿀 수 없어요. 값을 바꿔야 한다면 애초에 리스트를 쓰거나, t = (9,) + t[1:]처럼 새 튜플을 만들어야 합니다. 참고로 append, remove 같은 메서드도 튜플엔 없어요 — 대신 count, index는 쓸 수 있습니다.
▚ 주제 6 · import

남이 만든 코드 가져다 쓰기.

문제 16 방식 차이
from math import sqrt 로 불러왔을 때 올바른 사용법은?
정답: sqrt(16). from A import B는 B만 콕 집어 가져오는 방식이라, 모듈 이름 없이 바로 씁니다. 반대로 import math로 불러왔다면 항상 math.sqrt()처럼 앞에 모듈 이름을 붙여야 해요. 두 방식을 섞어 쓰면 헷갈리니 한 파일에선 통일하는 게 좋습니다.
문제 17 as
import pandas as pd 에서 as pd 가 하는 일은?
정답: 2번. as는 별명(alias)을 붙이는 키워드예요. 긴 모듈 이름을 매번 치기 번거로우니 짧게 줄이는 거죠. pandas → pd, numpy → np처럼 관례로 굳어진 별명들이 있어서, 그대로 따르면 다른 사람도 코드를 쉽게 읽을 수 있어요.
문제 18 표준 vs 외부
다음 중 설치 없이 바로 import할 수 있는 것은?
정답: json. json, math, random, os, datetime 등은 파이썬에 기본 내장된 표준 라이브러리라 바로 쓸 수 있어요. 반면 pandas·numpy·requests는 외부 라이브러리라 pip install로 먼저 설치해야 합니다. 설치 안 하고 import하면 ModuleNotFoundError가 나요.
주제별 점수가 함께 표시돼요. 빈칸은 대소문자·공백 무관.
