이번엔 짧은 조각이 아니라 하나의 완성된 프로그램이에요. 위에서 아래로 읽으면 실제로 돌아가는 코드이고, 빈칸 16곳이 흩어져 있습니다. 앞뒤 문맥과 주석을 단서로 채워보세요 — import, class, def가 전부 들어갑니다.

📋 요구사항
  • 책을 여러 권 등록하고, 남은 재고를 셀 수 있다
  • 회원은 최대 3권까지 대출 가능 (재고 없으면 실패)
  • 빌린 적 없는 책을 반납하면 예외를 던진다
  • 많이 빌린 순으로 순위를 매겨 출력한다
  • 상태를 JSON 파일로 저장하고 다시 불러온다

1. import
라이브러리를 통째로 불러오는 키워드. 이렇게 부르면 이후 json.dump()처럼 모듈 이름을 앞에 붙여 씁니다.
2. random
무작위 추천에 쓰이는 표준 라이브러리. 아래 random.choice(...)에서 실제로 사용되니, 그 이름을 보고 역추적할 수 있어요.
3. class
객체를 찍어내는 틀을 정의하는 키워드. 이 틀로 Library("코디세이 도서관")처럼 도서관 객체를 만듭니다.
4. __init__
객체가 만들어질 때 자동으로 한 번 실행되는 생성자. 앞뒤로 밑줄 2개씩입니다. 여기서 객체의 초기 상태를 준비해요.
5. name
밖에서 받은 매개변수 name을 self.name에 저장하는 자리. 오른쪽에 self.name을 쓰면 아직 없는 값을 참조해 에러가 납니다. "받은 재료를 객체 주머니에 담는다"로 기억하세요.
6. title
copies 횟수만큼 반복하며 제목을 서가에 추가. 반복 변수가 _인 이유는 "몇 번째인지는 안 쓰고 횟수만 필요"하기 때문이에요.
7. count
리스트에서 같은 값이 몇 개인지 세는 메서드. 같은 책을 2권 넣었다면 count("파이썬 입문")은 2를 돌려줍니다. (len()은 전체 개수라 여기선 안 맞아요.)
8. False
대출 실패를 알리는 값. 성공하면 True를 돌려주므로 호출한 쪽은 if lib.borrow(...)로 성공 여부를 판단할 수 있어요. 파이썬은 대문자 False입니다.
9. get
딕셔너리에서 키가 없을 때 기본값을 돌려주는 메서드. self.borrowed[member]로 접근하면 처음 빌리는 회원에게 KeyError가 나지만, get(member, [])은 빈 목록을 줘서 안전합니다.
10. remove
리스트에서 그 값 하나를 지우는 메서드. 책이 대출되면 서가에서 한 권 빠져야 하니까요. 같은 제목이 2권이면 하나만 지워집니다.
11. member
갱신한 대출 목록을 이 회원의 칸에 다시 넣는 자리. 위에서 get(member, [])으로 꺼내온 목록에 책을 추가했으니, 같은 키로 되돌려놔야 딕셔너리에 반영돼요. 처음 빌리는 회원이면 이 줄에서 항목이 새로 생깁니다.
12. raise
예외를 직접 던지는 키워드. 잘못된 요청을 조용히 넘기지 않고 즉시 알려서, 문제가 엉뚱한 곳에서 터지는 걸 막아요. 호출한 쪽은 except ValueError:로 받습니다.
13. sorted
정렬된 새 리스트를 돌려주는 내장 함수. 딕셔너리에는 .sort()가 없고, .sort()는 리스트를 제자리에서 바꾸며 None을 반환하기 때문에 return과 함께 쓸 수 없어요. 그래서 여기선 sorted가 맞습니다.
14. 1
enumerate는 기본이 0부터라 그냥 두면 "0위"가 나와요. start=1을 줘야 1위부터 시작합니다.
15. set
중복을 자동으로 제거하는 자료형. 같은 책이 2권 있어도 추천 후보엔 한 번만 나오게 하려는 거예요. set은 순서가 없어서 list(...)로 다시 감싼 뒤 random.choice에 넘깁니다.
16. FileNotFoundError
저장 파일이 아직 없을 때 나는 예외. 처음 실행하면 파일이 없는 게 정상이라, 프로그램이 죽지 않고 False를 돌려주도록 잡아줍니다. 함께 적힌 json.JSONDecodeError는 파일은 있지만 내용이 깨진 경우예요 — 둘을 튜플로 묶어 한 번에 처리합니다.
