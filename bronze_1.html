시간 제한 1초 · 메모리 128MB · 반복문 · 입력 처리

문제

온라인 쇼핑몰에서 물건을 담았습니다. 각 물건의 가격과 수량이 주어질 때, 총 결제 금액을 구하는 프로그램을 작성하세요.

입력

첫째 줄에 담은 물건의 종류 수 N이 주어집니다. (1 ≤ N ≤ 100)

둘째 줄부터 N개의 줄에 걸쳐 각 물건의 가격 P와 수량 C가 공백으로 구분되어 주어집니다. (1 ≤ P ≤ 10,000, 1 ≤ C ≤ 100)

출력

총 결제 금액을 출력합니다.

예제

예제 입력 1
3
1000 2
500 3
2000 1
예제 출력 1
5500

1000원짜리 2개(2000) + 500원짜리 3개(1500) + 2000원짜리 1개(2000) = 5500

예제 입력 2
1
7 7
예제 출력 2
49

힌트

    

      힌트 1 — 어떻게 시작할까?
      

        
① 먼저 물건이 몇 종류인지 알아야 반복 횟수를 정할 수 있어요. 첫 줄을 읽어 N을 구합니다.

        
② 총액을 담을 변수를 0으로 시작해 두고, 물건마다 더해 나갑니다.

        
③ 각 줄에서 가격 × 수량을 계산해 총액에 누적하면 끝이에요.

      

    

    

      힌트 2 — 한 줄에 두 숫자가 있을 때
      

        input()은 한 줄 전체를 문자열로 돌려줍니다. "1000 2"처럼요.
        
공백 기준으로 나누려면 .split(), 나뉜 조각을 한꺼번에 숫자로 바꾸려면 map(int, ...)을 씁니다.

        
price, count = map(int, input().split())

      

    

    

      힌트 3 — 반복 변수를 안 쓸 때
      

        N번 반복하되 지금이 몇 번째인지는 필요 없을 때는 변수 이름을 _로 씁니다.
        
for _ in range(n):
    ...

        
i라고 써도 동작은 같지만, _는 "이 값은 안 쓴다"는 뜻을 코드로 표현하는 관례예요.

      

    


    
정답

    

      정답 코드 보기
      

        
n = int(input())
total = 0

for _ in range(n):
    price, count = map(int, input().split())
    total += price * count

print(total)

        
한 줄씩 살펴보면

        
• n = int(input()) — 입력은 항상 문자열이라 int()로 바꿔야 반복 횟수로 쓸 수 있어요.

        
• total = 0 — 누적 변수는 반드시 반복문 밖에서 시작합니다. 안에 두면 매번 초기화돼 마지막 값만 남아요.

        
• total += price * count — 곱한 뒤 쌓습니다. =가 아니라 +=인 게 핵심.

        
• print(total) — 반복이 끝난 뒤 한 번만 출력합니다.

      

    

    

      자주 하는 실수
      

        
🔸 total을 반복문 안에서 0으로 초기화 → 매번 리셋되어 마지막 값만 남습니다.

        
🔸 print를 반복문 안에 넣음 → 줄마다 출력되어 오답.

        
🔸 int()를 빠뜨림 → "1000" * 2는 "10001000"이 됩니다.

        
🔸 들여쓰기 불일치 → IndentationError. 한 파일에서 공백 4칸으로 통일하세요.
